## 先說結論

《山景城小路》這篇文章指出，這道 Google 面試題考的不是資料結構，而是順序：陌生圖先抽象成問題，暴力解先寫對，瓶頸指名後才優化——跳步秀 Segment Tree 的人拿的是負面反饋。**題目本身是轉述見聞，無法驗證是否真為 Google 考題；但思路鏈（Interval → Overlap → Graph → Brute Force → Range Query）自洽且可操作，本文把建邊規則與複雜度逐項展開，並標出哪句是原文、哪句是推論。**

<p>題意：給定 N 個區間，每個區間是一個節點。兩個區間有重疊，就在對應節點之間連一條邊。例子：A = [1, 5]，B = [4, 8]，C = [7, 10]，D = [12, 15]；A↔B，B↔C，A 和 C 不相交，D 和誰都沒邊。</p>
<p>最直接的做法：兩兩比較區間，滿足 max(L1,L2) ≤ min(R1,R2) 就建邊，再 BFS／DFS 遍歷。構圖 O(N²)，遍歷 O(N+E)。思路鏈：Interval → Overlap Detection → Graph → Brute Force → 找瓶頸 → Range Query → Segment／Interval Tree。</p>
<p>但這題最值得記住的不是資料結構本身。很多人一上來就找優化方案，沒先把 Brute Force 寫出來，面試官反而給了負面反饋。理解題目 → 給出正確解 → 說清楚為什麼慢 → 找到瓶頸 → 一步步優化，這個順序不能跳。</p>

## 這篇文章真正解決的問題

【原文明說】面試官不給題面只給圖，第一關是「把陌生輸入抽象成已知問題」。這題的抽象只要兩步：區間是節點、重疊是邊；之後全是標準操作（建邊＋走訪＋優化）。練的不是某個資料結構，是「看到圖先問它是什麼問題」的反射。

## 流程拆解

### 1. 把圖抽象成問題：重疊即連邊

【原文明說】建邊規則：`max(L1, L2) ≤ min(R1, R2)` 即兩區間重疊。以貼文例子驗算：A=[1,5] 與 B=[4,8]，`max(1,4)=4 ≤ min(5,8)=5` 成立故連邊；B 與 C=[7,10]，`max(4,7)=7 ≤ min(8,10)=8` 成立；A 與 C，`max(1,7)=7 ≤ min(5,10)=5` 不成立；D=[12,15] 與誰都不重疊，故孤立。

![四個區間在數線上的位置、重疊標記，以及連邊後的圖。](/article.ai/articles/google-interval-graph-interview/figure-01-intervals-graph.svg)

<small class="figure-caption">圖 1｜本站依貼文例子自繪。注意 A 與 C 雖經由 B 連通，但兩者之間沒有直接邊——連通是走訪後的事，不等於連邊。</small>

### 2. 先寫暴力解：O(N²) 建邊，O(N+E) 走訪

【原文明說】最直接做法兩兩比較建邊，再 BFS／DFS 遍歷；N 一大 O(N²) 頂不住，真正的問題變成：給定一區間，如何快速找出所有與之重疊者——這時才輪到 Sweep Line、Interval Tree、Segment Tree 上場。

【從原文可直接推出】瓶頸不在走訪而在建邊：走訪已是線性，建邊的平方項才是優化目標；把「找重疊鄰居」認成 Range Query，是整題唯一的關鍵轉折，資料結構只是該轉折的標準答案。

### 3. Google 的順序：理解 → 正確 → 說慢 → 瓶頸 → 優化

【原文明說】值得練的能力是四個反射：見陌生圖先抽象成問題；見 Interval 想 Graph；見 O(N²) 找瓶頸；見 Range Query 才想資料結構。順序是理解題目 → 給出正確解 → 說清楚為什麼慢 → 找到瓶頸 → 一步步優化，不能跳。

![思路鏈與 Google 五步順序：資料結構是終點不是起點。](/article.ai/articles/google-interval-graph-interview/figure-02-thinking-chain.svg)

## 風險與盲點

- 【仍未被支撐的主張】「Google 最近面試題」是轉述見聞，無公司、職級、輪次資訊，無法驗證真偽；evidence 只能給探索中，當面經讀，不當考綱讀。
- 【合理推斷】「沒寫暴力先優化＝負評」符合 Google 公開的評分邏輯（先求正確再求複雜度），但單一見聞不能推出所有面試官都如此執行；穩妥讀法是把它當預設策略，而非鐵律。
- 【合理推斷】Sweep Line 在本題其實多半已夠用（端點排序掃一遍，排序主導複雜度），Interval Tree／Segment Tree 是把通用武器往上加；貼文並列三者是列選項，不是說三者都要寫出來。
- 【未被支撐】作者後續貼文給出 Python 解法（傳遞重疊視為同一 component，求 component value 和最大），本站未逐行驗證該程式碼，引用僅供延伸閱讀。
