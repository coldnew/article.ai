## 一句話結論

《chasm X 貼文》的技術主張基本成立：越獄 PS5 上 Qwen3.8-27B 跑出 20 tok/s、CPU 版約一分鐘一個 token，兩組數字在《abhi245y／PS5LM GitHub 倉庫》README 裡一字不差找得到；記憶體三連（DDR4 三個月漲 24%、AMD 漲顯存包價、5090 買不到）也全部對得上十月市況——炒作成分只有最後一句「PS5 進資料中心」，那是梗，不是路線圖。

## 這篇文章真正解決的問題

**《chasm X 貼文》解決敘事問題：**

把兩件看似無關的事焊在一起：遊戲機變成 AI 推理機，背景是顯存貴到連顯卡都買不起。當 GPU 現貨枯竭，任何帶 GDDR 的東西都會被重新估值——包括你客廳那台 PS5。

**《abhi245y／PS5LM GitHub 倉庫》解決技術問題：**

PS5 的 payload 只能拿到約 6 GiB 記憶體且沒有 GPU，原作者 Mert Cobanov（cobanov／PS5LM）先證明 llama.cpp 能在 PS5 的 Zen 2 CPU 上跑（代價是一分鐘一個 token）。這個 fork（abhi245y，加掛 PS5LM Plus 原生 App）解決的是 GPU 問題：以 title（原生應用）身份啟動，拿到主機 12 GiB 直連記憶體＋GPU，用 ggml 的 Vulkan 後端跑在 Mihawk-99 移植的 RADV 上，單一 11.44 GiB device heap。

### 頻寬帳：20 tok/s 物理上說得通嗎？

用 `python3 -c` 驗算（decode 速度 ≈ 頻寬 ÷ 模型大小，PS5 GDDR6 頻寬 448 GB/s）：

* 9.2 GiB × 20.3 tok/s ＝ 186.8 GB/s，佔 41.7%
* 6.8 GiB × 20.7 tok/s ＝ 140.8 GB/s，佔 31.4%
* 4.8 GiB（Gemma 4 E4B）× 61 tok/s ＝ 292.8 GB/s，佔 65.4%
* 1.9 GiB（Llama 3.2 3B）× 124 tok/s ＝ 235.6 GB/s，佔 52.6%

## 風險與盲點

**1. 前提是越獄，這是全部。** PS5 越獄只存在於特定韌體版本，升級即失效；Sony 的安全更新從來不是吃素的。這決定了 PS5LM 永遠是家釀玩具，不可能是產品，更不可能是資料中心方案——連作者自己都只做到「電視儀表板＋區域網路 OpenAI 相容 API」。

**2. 跑分是單一作者自測，無獨立復現。** tok/s 是 decode 速度，prompt 處理（prefill）速度另計；27B 量級在 32k／64k 上下文下的 KV cache 規劃是作者 planner 的選擇，換個配置數字會動。引用時要說「作者自測」，不要說「PS5 定論」。

**3. 記憶體價格數字的口徑要分清。** Barclays 的 24% 是 DDR4「合約價」三個月累計；現貨市場另有 TrendForce 的逐週數字；DigitalToday 的「DDR4 兩年漲近十倍」是 $0.9→$8.41／GB 的長期口徑。三個數字都對，但說的是三件事，混用即翻車。

**4. 把「顯存荒」當成「PS5 有價值」的因果鏈太長。** GDDR6 現貨從 $2.5 漲到 $7.5／GB（abit.ee 引述）解釋的是顯卡漲價，不是 PS5 套利空間——越獄機的供給彈性為零，炒一台少一台。

**5. 利益揭露：** 本篇作者（模型）無持倉、無相關利益；《chasm X 貼文》作者為一般帳號，無可查的商業漏斗；Barclays、TrendForce、TechPowerUp 均為行業常規信源，無付費牆引用。

## 可操作步驟

1. 想驗證跑分：照倉庫 `scripts/build-app.sh` 自行編譯（需 PS5_Vulkan 工具鏈），或等 releases 的 `ps5lm-app-vX.Y.Z.zip`＋`.sha256`；重點看 `docs/MODELS.md` 的 fit 規劃，不要只看 tok/s。
2. 想引用漲價數字：DDR4 用 Barclays／Guru3D 的「合約價三個月＋24%」口徑並註明日期（2026-10）；AMD 用 TrendForce 7 月＋10% kit 價；5090 用 Best Buy 現貨價 vs 1,999 美元 MSRP，三者不要混成一句話。
3. 想講「遊戲機跑模型」：正確定位是 llama.cpp＋Vulkan 移植工程的勝利（clean-room libc.prx、RADV 統一堆、GL 與 RADV 共 4,399 個符號名的連結處理，見 `docs/CONSOLE.md`），不是算力革命。
