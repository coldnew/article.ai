## 一句話結論

《思维怪怪 X 貼文》转述 Henry 的 ESP32 iPhone Agent 新版，技术细节与《onehumanbeing/esp32-iphone-agent GitHub 仓库 README》逐句相符、基本零走样，成立的部分是原理与限制全对；真正的新闻不是转述本身，而是 README 证明 v2 已把电脑踢出局——本系列前篇核实时还在 Roadmap 里写着的 drop the computer 已经落地，v0.1.0 旧版归档 legacy。但书有两处：No Mac 与一键热点要付费账号的张力，以及 MIT 之外的 GPL-3.0 尾巴。

## 這篇文章真正解決的問題

**《思维怪怪 X 貼文》解决叙事问题：**

Henry 的项目在中文信息流里已经出现过一次（本系列前篇四路线文的 3 号位，当时还是要 Mac／Linux 跑 UxPlay 的旧版）。这次转述回答：新版到底变了什么——答案是电脑没了，只剩板子加本机 App，以及一长串诚实到有点劝退的限制。

**《esp32-iphone-agent README》解决技术问题：**

不用越狱、不用 XCTest、不用开发者账号（有但书），只用 AirPlay 拿眼睛、USB HID 拿手，在同一部手机上跑 Agent，把 iPhone-use 的门槛压到一块 $7 的板子。

### 本次真正的增量：computer is gone

README 置顶宣告新版，旧版（Mac／Linux 跑 UxPlay＋Python server）保留为 v0.1.0 tag 与 legacy 分支。前篇核实里 Roadmap 的第一条就是 drop the computer，现在勾掉了； landscape、中文输入、多动作合并仍在路上。评论区有人问弹窗验证码怎么办——README 没直接回答，只说了口令、Apple Pay、DRM 画面不投屏，通用 planner 如何处理异常弹窗属于开放问题。

## 風險與盲點

**1. 两处但书：**

其一，About 写的 no developer account 与 Quick start 并存：免费 Apple ID 能签（7 天重签），但一键加热点要 Hotspot Configuration 能力即付费账号，否则手动输密码。其二，授权不是纯 MIT：airplay/ 目录系 UxPlay 移植、GPL-3.0，链接后的固件二进制按 GPL-3.0 分发——前篇只写了 MIT，这里补上。

**2. 实现落差：**

每步数秒、大半耗在模型；App 用了私有 suspend API，自用无妨、上架前得换；相关项目表承认 boboabw/phone-agent 是最接近的竞品，差距只在眼睛（板载 AirPlay）。

**3. 转述链定位：**

《思维怪怪》账号自介是 AI Shit Post 信息流＋Telegram 频道，属转述聚合、非一手；Henry 本人（Antler backed、NYU、ex-Tencent）在评论区挂了原帖，新版 $7 无电脑的说法以 README 为准 consistent。作者开发用的是自家两台 DGX Spark 跑 Qwen3.8-Flash，复现成本另计。
