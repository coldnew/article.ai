## 流程拆解：從名詞到動手順序

### 一詞兩義：OS kernel vs GPU kernel

【原文明說】開頭先拆彈：「kernel」這個詞被兩個世界共用。在作業系統裡，它是介於軟體與硬體（CPU、記憶體）之間的核心程式；在 GPU 程式設計裡，它是「被丟到數千個執行緒上同時跑的函式」，NVIDIA 出貨就附的 cuBLAS 正是 matmul、矩陣向量乘、內積等預編譯 kernel。當有人說「我寫了一個 kernel」，指的永遠是後者。

【原文明說】GPU kernel 的核心意象用五行虛擬碼講完：每個執行緒靠自己的 thread ID 認領一塊記憶體，做完數學寫回去——全程沒有迴圈，迴圈被執行緒數量取代了。

### 跑一次模型：CPU 排隊，GPU 消化

【原文明說＋已驗證】`torch.matmul(a, b)` 背後是四步發射鏈：PyTorch 看到 GPU 陣列選 GPU 版函式 → 掉進 cuBLAS／cuDNN 等預編譯函式庫（或 PyTorch 自寫 kernel）→ 函式庫告訴驅動「程式碼和資料指標在這，用這麼多執行緒跑」→ CPU 把發射丟進佇列就去執行下一行 Python，GPU 依序消化。所以跑一次模型，本質是 CPU 排了數百次 kernel 發射。用 profiler 看 GPU 時間軸，會看到數百個小盒子排開，每個都是一個 kernel——而每次發射有數微秒的固定成本，積少成多。

![torch.matmul 背後四步發射鏈與 GPU 時間軸小盒子。](/article.ai/articles/gpu-kernel-intro/figure-01-launch-path.svg)

<small class="figure-caption">圖 1｜本站自繪：四步發射鏈（分派→函式庫→驅動→排隊）＋ profiler 時間軸示意。小 kernel 越多，發射開銷佔比越高，越值得 fuse。</small>

### 為什麼值得 fuse：HBM 大而慢，SRAM 小而快

【原文明說＋已驗證】GPU 由又慢又大的 HBM 和又小又快的 SRAM 組成，兩者頻寬約數 TB／s，但計算核心的算力遠超這個數字——所以推論時核心多半在閒等資料。標準 PyTorch 流程裡「乘法→加常數→啟動函數」是三個 kernel：每次從慢記憶體讀進來、做一點點數學、再寫回去，來回三趟。自寫 kernel 則讀一次，在 SRAM 裡把三步全做完，寫回一次——這就是 "fused" 的意思。

【原文明說＋已驗證】FlashAttention 是招牌例子：標準 attention 先把完整注意力矩陣寫回 HBM，再讀回來做 softmax、乘 V；FlashAttention 改成分塊（tile）在 SRAM 內算完 softmax×V，累加後才換下一塊。作者也老實補一句：分塊做起來其實很難，需要聰明的演算法。

![未融合三次往返 vs 融合後一次往返。](/article.ai/articles/gpu-kernel-intro/figure-02-fusion.svg)

<small class="figure-caption">圖 2｜本站自繪：左側三個 kernel 各自讀→算→寫，右側 fused kernel 讀一次、全程 SRAM、寫回一次。FlashAttention 即右側思路的分塊版。</small>

### 性感但排最後：無聊的優化先抄完

【原文明說】全文真正的排序題在這節：手寫 kernel 能改善 TTFT、每 token 延遲、吞吐，但大頭增益都在上面那些「不性感」的層——batching（多請求併成一次 forward）、量化（16 位改 8／4 位，少讀就是快）、推測解碼（小模型先猜、大模型一次驗）、編譯器（ML compiler 先自動 fuse 一輪）、以及 prefix caching、prefill／decode 分拆、paged attention 等。推論系統慢，八成是上面這些沒做滿；手寫 kernel 工時貴，要等上面全快了才划算。

【原文明說】動手路徑也給了：NVIDIA GPU 先用 Triton（寫一個資料塊的邏輯，它幫你生 GPU 碼，到位八成），要完全控制再下 CUDA；旁邊還有 ThunderKittens、TileLang、CuTe、Mojo 等 kernel DSL 在比「控制 vs 好寫」的取捨。文末推薦 Horace He 的〈Making Deep Learning Go Brrrr From First Principles〉當效能工程入門（只給標題，請自行搜尋）。

## 風險與盲點

- **入門文，不是研究**：44 個區塊全是既有知識重述，無新數據、無 benchmark；evidence 只能給「探索中」。它的價值是排序與表達，不是新知。
- **教學簡化有一處**：vec-add 範例說陣列「在 shared memory 裡」，嚴格講這類全域陣列住的是 global memory，shared memory 是 block 內要顯式管理的暫存——入門可接受，但照抄去考試會錯。
- **有一張圖是 AI 生的**：作者自承第二張 GPU 示意圖是 Claude 畫的，數字稱來自 H100 但沒給出處；轉述時請當示意，不當規格。
- **作者與雇主同向**：Gimlet Labs 就是做 serverless inference＋AI 自動生成 kernel 的公司，9/4 才宣布 3 億美元 B 輪（本站查證官網與部落格，kernel 生成正是其 kforge 主力方向）。本文無產品推銷，但選題與雇主議程一致，閱讀時打個折。
